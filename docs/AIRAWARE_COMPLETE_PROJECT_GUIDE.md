## Production-Grade Urban Air Quality & Personal Exposure Intelligence Platform
### Exclusively Designed for Mobile (Android / iOS)

## 1. Executive Summary & Project Vision

**AirAware Pune** is an end-to-end, real-time atmospheric telemetry and personal inhalation exposure tracking platform purpose-built for the Pune Metropolitan Region (encompassing PMC, PCMC, Pune Cantonment, and Hinjawadi MIDC corridors).

Unlike typical demonstration or mockup projects that rely on synthetic static data, mock timers, or hardcoded strings, **AirAware** is engineered as a true production system:
1. **Live Multi-Source Sensor Ingestion**: Real-time atmospheric telemetry is ingested from official government Central Pollution Control Board (CPCB) continuous ambient air quality monitoring stations (CAAQMS), European Centre for Medium-Range Weather Forecasts (ECMWF CAMS via Open-Meteo), and meteorological ground observation stations.
2. **PostgreSQL 15+ & PostGIS Spatial Engine**: Atmospheric observations are normalized and computed according to the Indian National Air Quality Index (CPCB NAQI) standard across 49 spatial stations in Pune, backed by spatial indexing (`ST_DWithin`, `ST_Distance`).
3. **Machine Learning Pipeline**: Diurnal XGBoost temporal AQI forecasting, DBSCAN spatial pollution cluster hotspot detection, and Isolation Forest sensor anomaly telemetry are generated by an asynchronous FastAPI backend.
4. **Mobile-First Client**: A high-performance Flutter mobile application featuring real background/foreground GPS exposure tracking via Android foreground services, real-time local push notifications with cooldown deduplication, crowdsourced citizen incident reporting, and 5 dynamic respiratory health personas.

### Pillar I: Zero-Fake Ingestion & CPCB Standard Mathematics
Every AQI value displayed across Pune is calculated using the official CPCB sub-index piecewise linear formula:
$$I_p = \frac{I_{hi} - I_{lo}}{B_{hi} - B_{lo}} \times (C_p - B_{lo}) + I_{lo}$$
where $C_p$ is pollutant concentration, $[B_{lo}, B_{hi}]$ is the concentration breakpoint category, and $[I_{lo}, I_{hi}]$ is the corresponding sub-index range. The overall AQI is the maximum sub-index across all measured criteria pollutants ($PM_{2.5}, PM_{10}, NO_2, SO_2, CO, O_3, NH_3$).

### Pillar II: Native Android Background Tracking & Foreground Service
The Personal Exposure Mode operates using Android's native foreground execution:
* Configures an active foreground notification pinned to the Android notification drawer (`ForegroundNotificationConfig`), preventing Android OS battery optimization from killing location sampling while the user runs, walks, or commutes.
* Calculates cumulative traveled distance using the Great-Circle Haversine formula via `Geolocator.distanceBetween()`.
* Samples the nearest monitoring station along the route.
* Estimates actual micrograms ($\mu\text{g}$) of $PM_{2.5}$ inhaled based on minute-by-minute respiratory ventilation volume equations:
$$\text{Dose } (\mu\text{g}) = \text{Ventilation Rate } (\text{m}^3/\text{hr}) \times \frac{\text{Duration (seconds)}}{3600} \times C_{PM2.5} (\mu\text{g}/\text{m}^3)$$

### Pillar III: Personal Safety Notifications & Smart Deduplication
Instead of spamming the user or relying on fake timers:
* Integrates `flutter_local_notifications` targeting Android notification channels (`airaware_alerts` with `Importance.high`).
* Checks user-defined threshold triggers against real-time telemetry from the user's nearest Pune monitoring station.
* Features a 30-minute cooldown suppression window to protect device battery and user focus, allowing immediate bypass only if AQI surges drastically ($\ge 50$ points into Severe/Hazardous).

### Pillar IV: Crowdsourced Citizen AirWatch Feed
* Allows verified residents to report local biomass burning, construction dust, or industrial emissions.
* Automatically captures high-precision device GPS coordinates (`latitude`, `longitude`) upon reporting.
* Stores reports directly in PostgreSQL `citizen_reports` table.
* Enables community confirmation via upvoting (`POST /citizen-reports/{id}/vote`), increasing visibility for municipal authorities (PMC / PCMC).

## 4. Mobile Execution & Environment Configuration

### Android Permissions Declared in `AndroidManifest.xml`:
* `android.permission.INTERNET`: Telemetry queries and Supabase communication.
* `android.permission.ACCESS_FINE_LOCATION`: Exact GPS positioning for nearest station lookup and exposure breadcrumbs.
* `android.permission.ACCESS_COARSE_LOCATION`: Cellular/Wi-Fi positioning fallback.
* `android.permission.POST_NOTIFICATIONS`: Android 13+ runtime push notifications for AQI threshold breaches.
* `android.permission.FOREGROUND_SERVICE`: Continuous background execution during active outdoor tracking sessions.
* `android.permission.FOREGROUND_SERVICE_LOCATION`: Android 14+ required foreground service type for location tracking.
* `android.permission.VIBRATE`: Haptic alerts during critical pollution warnings.

## 5. Security, Row Level Security (RLS) & Privacy

1. **Guest Mode Access**: Unauthenticated citizens can inspect Pune city air pulse, interactive map, station details, diurnal forecasts, and hotspot telemetry without mandatory sign-in.
2. **Protected Private Data**: Personal saved locations (`saved_locations`), exposure sessions (`exposure_sessions`), and personalized alert triggers (`user_alerts`) are guarded by Supabase PostgreSQL Row Level Security (RLS) policies:
   ```sql
   CREATE POLICY "Users can only access their own exposure sessions"
   ON exposure_sessions FOR ALL
   USING (auth.uid() = user_id);
   ```
3. **Password Security**: Managed by Supabase Auth using industry-standard bcrypt/Argon2 hashing with secure JWT refresh token rotation.
